Connected to the workbook
The tracker is open full screen over Excel. Keep this pane open: full screen reads and saves through it.
How to run the report
  1. Navigate to NextGen PM.
  2. Locate the "Reports" menu option on the top-left.
  3. Click "Memorized".
  4. Change the Report Type drop-down to "Appointment Reports" and select "1 Appt List - ALL TMS".
  5. Select "OK" to run the report.
  6. Export the report by clicking the x symbol beside the bar graph icon .
  7. Copy the file from your NextGen File Explorer and upload it on Import here.
New patients in NextGen need a tracker ()
Active tabs with no MRN in A4 ()
Without it, imports and benefits can't find the patient. Enter it from NextGen.
Create a tracker here? ()
Their MT is at another clinic, but 16 or more daily treatments are booked here. Create a tab here if this clinic will enter their pulses. Otherwise they stay a guest, and their pulses go on their home clinic's tab.
Guest patients need a link to their tab ()
Most of their chair visits are at another clinic, so that clinic carries the tab. Paste the link to their tab on that clinic's tracker: pulses, technician and measures are entered there. The list is on the Guest Patients sheet.

Import

Bring in the NextGen appointment list and Sohar benefits. Nothing changes until you apply the preview.

NextGen appointment list

Choose or drop the "1 Appt List - ALL TMS" export. The preview appears right away.

Sohar benefits

Upload the "Final tracker file (TMS + ESK)" from the Sohar Eligibility add-in (the older "Benefits (TMS Tracker)" file works too). Patients booked only for ESK are left out. Tabs are matched by MRN. Blank deductible, out-of-pocket and insurance cells are filled; a tab that already has a different amount is shown unticked, because W4 and W5 hold the amounts at the start of the course.

Workbook tools

The tab you choose is renamed New Template and the current New Template is deleted (it asks first). Patient tabs and the add-in's own sheets aren't listed. The workbook's version history can bring the old one back.

Rows with an appointment date take row 10's formatting and empty rows go back to the template's gray. This also runs on every import and once each time the add-in opens. Rows you colored yourself are left alone.

Add patient

Copies New Template and names the tab by LASFIR (SMIJAN, then SMIJAN 2 for a later course). Names are not saved. The protocol is chosen at the MT.

Authorization

A standard course is 36 treatments: the MT (90867), an MT redo (90869) when authorized, and the rest daily (90868).
